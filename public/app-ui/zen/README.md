# Zen article illustrations

New illustrations of Zen, the Cortisol+ mascot, for website articles. They match the full-body app art (`app-ui/start/zen_presenting.webp`, `zen_explain.webp`): curly dark hair, cream T-shirt with mint, lilac and pink blobs, coral shorts, blue sneakers, and thin dark-brown outlines.

All files have transparent backgrounds and are cropped tight. Full-body images are 480px tall; waist-up images are 480x480. They were generated with Higgsfield GPT Image 2.6 using the existing Zen art as references, then had their backgrounds removed. Reference them as `/app-ui/zen/<file>`.
